# Periphery 環繞延伸

看影片時，把主螢幕的畫面「延伸」到左右兩側螢幕，營造類似 ScreenX 的環繞沉浸感。

這個外掛參考 MIT Media Lab 的 Infinity-by-Nine 研究。人的餘光本來就看不清楚，所以側螢幕不需要清晰的畫面，只要顏色、亮度和動態跟主畫面一致，大腦就會把它當成畫面的延伸。

---

## 安裝（約 1 分鐘）

1. 從 GitHub Releases 下載 `periphery-x.y.z.zip`，解壓縮到一個固定的資料夾，之後不要移動或刪除這個資料夾。
2. 在 Chrome 網址列輸入 `chrome://extensions` 並按 Enter。
3. 打開右上角的 **開發人員模式**。
4. 按 **載入未封裝項目**，選擇剛剛解壓縮出來的資料夾，也就是裡面有 `manifest.json` 的那一層。
5. 建議把外掛釘選到工具列：按拼圖圖示，再按 Periphery 旁邊的圖釘。

> Edge、Brave 等以 Chromium 為基礎的瀏覽器也可以用相同方式安裝。

## 使用方式

1. 在 YouTube 或其他影片網站上**先播放影片**。
2. 按工具列的 Periphery 圖示，再按 **開啟環繞模式**，或直接按快捷鍵 **Alt+Shift+S**。
3. 左右螢幕會自動開啟全螢幕的延伸畫面。
4. 接著把影片切到全螢幕，例如在 YouTube 按 `F`。
5. 要關閉時，再按一次 **Alt+Shift+S**，或在側螢幕上按 **Esc**。

外掛會用瀏覽器視窗目前所在的螢幕當作主螢幕，左右兩側的螢幕會自動判斷。

### 本機影片

工具列選單裡有 **本機影片播放器**。把影片檔拖進去，就能使用完整的環繞效果。在播放器裡按 `S` 開關環繞，按 `F` 切換全螢幕。

如果直接把檔案拖進 Chrome 播放，只能使用簡化的相容模式，所以建議用內建播放器。

## 調整設定

- **工具列選單**：可以切換風格（標準／柔和／鮮明／純色光），也有最常用的 5 個滑桿：亮度、效果強度、清晰度、延伸倍率、跟隨鏡頭運動。
- **全部設定**：在選單按「全部設定…」，會開啟完整的設定頁，共 20 多項細節可以調整。設定頁上方有三螢幕的**即時預覽**，也可以換成自己的影片來預覽。
- **還原預設**：
  - 單一項目：按該項目右邊的 ↺，或在滑桿上連點兩下。
  - 全部項目：按「全部還原預設」，或選單裡的「還原預設」。
- **我的設定**：調到喜歡的效果後，按「把目前設定存成『我的設定』」，之後一鍵就能切回來。

所有調整都會**即時套用**到正在播放的環繞畫面。

## 它做了什麼

- **自動去除黑邊**：偵測電影上下（或左右）的黑邊，只從真正的畫面邊緣取色。
- **邊緣延伸**：取主畫面最外側一小條區域的顏色往外延伸。距離越遠，上下擴散越多，形成柔和的光錐，不會變成生硬的橫條。
- **鏡頭跟隨**：每一格畫面都會估算鏡頭的水平和垂直移動。鏡頭搖動時，移出畫面的內容會被「推」到側螢幕上繼續移動。
- **漸進模糊與漸暗**：靠近主螢幕的地方較清楚，越往外越模糊、越暗，符合人眼周邊視覺的特性。
- **場景切換偵測**：剪接時兩側立即重置，不會殘留上一個場景的顏色。
- **去色帶**：加入極細微的雜訊（dithering），避免大面積漸層出現一圈一圈的色階。
- 全部運算都在 GPU（WebGL2）上執行，對播放效能影響很小。

## 限制與常見問題

**Netflix、Disney+ 等平台無法使用**
這些平台使用 DRM 加密，瀏覽器會刻意阻止任何程式讀取畫面。這是瀏覽器的設計，外掛無法繞過。外掛偵測到 DRM 時會直接提示。

**部分網站顯示「相容模式」**
有些網站的影片放在別的網域，又沒有開放跨來源讀取。這時外掛會改用簡化版的效果，沒有鏡頭跟隨和黑邊偵測。

**沒有偵測到側螢幕**
請確認 Windows 的「設定 → 系統 → 顯示器」中，螢幕的排列方式和實際擺放的位置一致。偵測不到時，外掛會改開兩個預覽小視窗。也可以在「進階」裡手動指定左右螢幕。

**選單顯示「授權並開啟」**
這代表影片位在其他網站的嵌入式播放器裡。按下按鈕並同意授權後，就可以正常使用。

**側邊視窗沒有出現**
第一次在某個網站開啟時，外掛會自動允許該網站開啟彈出式視窗，因為側邊畫面是由網頁開啟的視窗。如果仍被擋住，請在網址列右側允許彈出式視窗。

**本機檔案（file://）沒有反應**
請到 `chrome://extensions` → Periphery → 詳細資料，開啟「允許存取檔案網址」。或者直接改用內建的本機影片播放器。

**快捷鍵和其他程式衝突**
可以到 `chrome://extensions/shortcuts` 修改快捷鍵。

**不小心點到側螢幕**
外掛會自動把焦點切回主視窗，空白鍵等快捷鍵仍然會作用在影片上。

## 權限說明

| 權限 | 用途 |
|---|---|
| 目前分頁（activeTab） | 只在你按下圖示或快捷鍵時，讀取那個分頁的影片畫面。 |
| 顯示器資訊 | 偵測左、中、右螢幕的位置。 |
| 內容設定 | 允許你開啟環繞模式的網站開啟彈出式視窗，也就是側邊畫面。 |
| 儲存空間 | 儲存你的調整設定。 |
| 所有網站（選用） | 只有影片在其他網域的嵌入式播放器裡時，才會詢問你是否授權。 |

整個外掛完全在本機執行，沒有任何網路連線或資料收集。
