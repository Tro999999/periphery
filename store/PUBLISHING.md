# 上架到 Chrome 線上應用程式商店：步驟

上架之後，別人只要打開商店頁面，按「加到 Chrome」就能安裝，不需要開發人員模式。之後你更新版本，使用者也會自動收到更新。

## 你需要準備

| 檔案 | 用途 |
|---|---|
| `periphery-1.0.0.zip` | 要上傳的套件（manifest.json 位在壓縮檔最外層） |
| `screenshot-1.png` ~ `screenshot-4.png` | 商店截圖（1280×800） |
| `promo-tile-440x280.png` | 小型宣傳圖塊 |
| `LISTING.md` | 說明文字和權限說明，可以直接複製貼上 |
| `privacy-policy.html` | 隱私權政策，需要放到網路上 |

## 步驟

### 1. 註冊開發人員帳號（只需要做一次）
1. 前往 Chrome 線上應用程式商店開發人員資訊主頁：https://chrome.google.com/webstore/devconsole
2. 用 Google 帳號登入。官方建議另外開一個專門用來上架的帳號，因為之後**無法更改**這個帳號的 email。
3. 同意開發人員協議，並支付一次性的註冊費（5 美元）。

### 2. 把隱私權政策放到網路上
最簡單的作法有兩種，任選一種：
- **GitHub Pages**：建立一個公開的 repo，上傳 `privacy-policy.html`，在 Settings → Pages 開啟後，就會得到一個網址。
- **Google 協作平台（Google Sites）**：建立一個新網站，把內容貼上後發布。

### 3. 上傳套件
1. 在資訊主頁按「新增項目」，上傳 `periphery-1.0.0.zip`。
2. **商店資訊**分頁：
   - 詳細說明：貼上 `LISTING.md` 的中文說明
   - 類別：娛樂
   - 上傳圖示：會自動使用套件內的 128×128 圖示
   - 上傳 4 張截圖和小型宣傳圖塊
3. **隱私權實務**分頁：依照 `LISTING.md` 下半部的內容填寫，並貼上隱私權政策網址。
4. **發布範圍**分頁：
   - **公開**：所有人都能在商店搜尋到
   - **不公開（Unlisted）**：只有拿到連結的人才能安裝，適合先分享給朋友測試
5. 按「提交審查」。

### 4. 等待審查
審查通常需要幾天，有時需要一到兩週。審查通過後會寄信通知，你就能拿到商店連結分享給別人。

這個版本已經盡量降低審查風險：
- 只使用 `activeTab`（使用者按下圖示時才存取該分頁），沒有要求「讀取所有網站」的權限
- 不需要 `tabs` 權限，所以不會出現「讀取你的瀏覽紀錄」警告
- 存取其他網站的權限設為**選用**，只有遇到嵌入式播放器時才會詢問使用者

### 5. 之後要更新
1. 修改 `manifest.json` 裡的 `version`（例如 `1.0.0` → `1.0.1`）
2. 重新壓縮整個資料夾，壓縮檔最外層必須是 `manifest.json`
3. 在資訊主頁的「套件」分頁上傳新的 zip，然後提交審查

## 不上架商店的分享方式（給少數朋友用）

直接把 zip 傳給對方，請對方依照 `README.md` 用「開發人員模式 → 載入未封裝項目」安裝。

缺點有三個：每次開 Chrome 可能會跳出提醒、不會自動更新，而且對一般人來說步驟比較麻煩。如果要給很多人用，還是建議上架商店。
